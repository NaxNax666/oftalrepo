Пациент

Цель — это указание программе: ввод в лазер подбирается так, чтобы прогнозный сфероэквивалент на выбранный срок был равен цели (например, +0.25 D через 3 мес). Цель и срок сохраняются в базе вместе с пациентом.

Данные до операции

ODOS
Субъективная рефракция — как при подборе очков; острота с коррекцией — десятичная (0.1–1.5). Кератометрия и биометрия — с Nidek AL-Scan. Кератометрия (K1, K2 и их оси) участвует в подборе цилиндра и оси — заполняйте её полностью.
Протокол WLP (WaveLight Plus): дополнительно внесите рефракцию, измеренную InnovEyes. Расчёт ведётся от субъективной рефракции (если её нет — от InnovEyes); расхождение приборной и субъективной рефракции показывается в результате.
Лоскут — ожидаемая толщина для головки Moria M2 (если пусто — мкм). Глаз без рефракции не рассчитывается. Десятичный разделитель — точка или запятая.
Если указан № карты, пациент автоматически сохраняется в базу со статусом «запланирован»; после операции подтвердите фактический ввод и лоскут на вкладке «База пациентов и осмотры».

База пациентов

Расчёт для списка пациентов

1. Скачайте шаблон, заполните по строке на каждый глаз (строку-пример можно удалить).
2. Загрузите заполненный файл — получите Excel с рекомендациями для каждого глаза.

Сводная таблица номограммы

Ввод в лазер для «типичного» глаза (средняя биометрия по вашим данным), цель — сф. экв. 0 D (значение по умолчанию из настроек). Роговичный астигматизм в таблице принят равным рефракционному и на той же оси. Для конкретного пациента точнее вкладка «Расчёт пациента»: там учитывается его кератометрия, пахиметрия, лоскут и т.д.

Сфера (цилиндр 0): субъективная → ввод, по возрасту
