# Номограмма LASIK · Alcon WaveLight EX500 + Moria M2

Программа подсказывает, **что вводить в лазер EX500**, чтобы получить целевую рефракцию
(по умолчанию эмметропию) через заданный срок после операции. Номограмма строится на результатах
ваших собственных операций и **уточняется по мере добавления новых результатов** — переобучение
делается одной кнопкой.

![Интерфейс программы](/docs/интерфейс.png)

> Рекомендация — вспомогательная. Окончательное решение, проверка глубины абляции и остаточного
> ложа на лазере остаются за хирургом.

## 1. Быстрый старт (Windows)

**Один раз на компьютере:**

1. Установите Python 3.11 или новее: <https://www.python.org/downloads/>.
   В первом окне установщика **обязательно поставьте галочку «Add python.exe to PATH»**.
2. Скопируйте папку с программой в любое место (например, на рабочий стол).

**Каждый раз:**

1. Дважды щёлкните файл **`Запуск.bat`**.
2. При первом запуске программа сама скачает нужные компоненты (1–5 минут, нужен интернет).
   Следующие запуски — несколько секунд, интернет не нужен.
3. Автоматически откроется браузер со страницей программы (адрес `http://127.0.0.1:8765`).
   Если не открылся — откройте этот адрес вручную.
4. Чёрное окно не закрывайте, пока работаете. **Закрыли окно — программа остановлена.**

Программа работает только на вашем компьютере: данные пациентов никуда не отправляются.

**macOS / Linux:** установите Python 3.11+, затем на macOS дважды щёлкните `Запуск.command`
(при первом запуске, возможно, потребуется в Терминале выполнить `chmod +x Запуск.command запуск.sh`),
на Linux — выполните `bash запуск.sh`.

## 2. Работа с программой

### Вкладка «Расчёт пациента»

1. Заполните возраст, протокол (Custom-Q / WFO), оптическую зону, цель и срок, на который
   оптимизируется результат (по умолчанию 3 месяца).
2. Для каждого глаза введите:
   - **субъективную рефракцию** (сфера, цилиндр, ось) — как при подборе очков;
   - **кератометрию и биометрию с Nidek AL-Scan** (K1, K2 с осями, AL, ACD, пахиметрия, зрачок);
   - **ожидаемую толщину лоскута** для головки Moria M2 (если пусто — 110 мкм).

   Неизвестные поля можно оставить пустыми — будут подставлены средние значения по вашей базе,
   но точность расчёта при этом ниже. Глаз без сферы не рассчитывается (можно считать один глаз).
3. Нажмите **«Рассчитать»** (или Enter).

Для каждого глаза выводится:

| Что | Пояснение |
|---|---|
| **ВВЕСТИ В ЛАЗЕР** | рекомендуемые сфера / цилиндр / ось для ввода в EX500 |
| Поправка к субъективной | насколько ввод отличается от субъективной рефракции |
| Прогноз через N мес | ожидаемый сфероэквивалент и рефракция |
| Точность | «80 % глаз в пределах ± X D» — реальный разброс результатов на ваших данных |
| Если ввести субъективную | прогноз, если ввести рефракцию без номограммы — для сравнения |
| Прогноз по срокам | ожидаемая динамика от 1-х суток до 12 месяцев |
| Абляция, RSB, PTA | ориентировочная глубина абляции (по Мюнерлину), остаточное стромальное ложе, доля изменённой ткани |
| Предупреждения | тонкое ложе (< 300 мкм), PTA > 40 %, рефракция вне диапазона базы, гиперметропия (мало данных), неизвестный протокол |

Кнопка **«Печать»** печатает результат (или сохраняет в PDF через диалог печати браузера).

### Вкладка «Список пациентов (Excel)»

Для расчёта сразу многих глаз: скачайте шаблон, заполните по строке на каждый глаз, загрузите —
получите Excel с рекомендациями и прогнозами.

### Вкладка «Таблица номограммы»

Классическая таблица «субъективная рефракция → ввод в лазер» по возрастам, отдельно для каждого
протокола, для «типичного» глаза (средняя биометрия вашей базы). Удобно распечатать и держать
в операционной как ориентир. Для конкретного пациента точнее вкладка «Расчёт пациента».

### Вкладка «Данные и обучение»

Сводка текущей модели, загрузка новых данных, проверка данных, переобучение, отчёты и история версий.

## 3. Как добавлять данные и переобучать модель

Чем больше в базе операций **и особенно контрольных визитов через 3–6–12 месяцев**,
тем точнее номограмма.

### Способ А — дописать в основной файл (рекомендуется)

1. Откройте `номограмма.xlsx` в Excel.
2. Добавьте новых пациентов строками ниже существующих **в тех же колонках**; для уже
   прооперированных дописывайте результаты контрольных визитов (1, 3, 6, 9, 12 мес) в их строки.
3. **Сохраните** файл (программа видит только сохранённые изменения).
4. В программе: вкладка «Данные и обучение» → **«Проверить данные»** → исправьте найденные
   ошибки ввода (указан номер строки Excel) → **«Переобучить модель»**.

### Способ Б — отдельный файл

Сделайте копию `номограмма.xlsx`, удалите старые строки, внесите новые и загрузите файл кнопкой
«Загрузить» на вкладке «Данные и обучение» (файл сохранится в папку `данные`).
Если пара «id + глаз» встречается в нескольких файлах — используется запись из загруженного файла
(так можно дополнять старых пациентов новыми визитами).

### Правила заполнения

- Шапку таблицы (первые две строки) **не менять**. Новые колонки можно добавлять — см. раздел 7.
- Одна строка = один глаз; `id` — номер карты, `глаз` — OD или OS.
- Цилиндр можно записывать как с «−», так и с «+» — программа это учитывает.
- «Запланировано в лазере» — **то, что фактически ввели** в лазер.
- «flap» — толщина лоскута, **измеренная в операционной**.
- «после операции» — ранний осмотр (считается 1-е сутки), рефракция — Tonoref II, острота — без коррекции.
- Осложнения записывайте в «коментарий» — такие глаза автоматически не используются в обучении
  (чтобы осложнения не искажали номограмму).
- Пустые клетки допустимы: визит без рефракции просто не учитывается.

### Что происходит при переобучении

- Все файлы читаются заново, ошибки ввода отсеиваются (см. раздел 4.3).
- Модель обучается на всех данных, её точность проверяется честной кросс-валидацией.
- **Прошлая версия модели проверяется на новых глазах, которых она не видела** — это самая
  объективная оценка того, насколько номограмма работает на практике. Результат виден в сводке
  и в истории версий.
- Все версии сохраняются в папке `модели` (`модель_ДАТА_ВРЕМЯ.joblib`), история — в
  `модели/история_обучения.csv`, подробный отчёт — в `результаты/отчёт_обучения_ДАТА_ВРЕМЯ.xlsx`.
- Если модель оказалась не точнее простой поправки (мало или шумные данные), в сводке появится
  предупреждение «ВНИМАНИЕ».

**Откат к прошлой версии:** скопируйте нужный файл `модели/модель_….joblib` поверх
`модели/актуальная.joblib` и перезапустите программу.

### 4.2. Текущая практика и что показали результаты

- **Ввод в лазер уже содержит «ручную» поправку:** при миопии вводится в среднем на **0.44 D больше**
  субъективной сферы (типично −0.5 D), при гиперметропии — на ~0.5 D меньше.
- **Результат со временем смещается в миопию (регресс).** В среднем по одним и тем же глазам
  относительно раннего осмотра: к 1 мес −0.13 D, к 3 мес −0.14 D, к 6 мес −0.5 D (по 6 мес пока всего 28 глаз).
  Ранний осмотр в среднем +0.27 D (небольшая гиперкоррекция), к 3 мес — около эмметропии.
  Поэтому номограмма оптимизируется **на заданный срок** (по умолчанию 3 мес), а не на 1-е сутки.
- **Что влияет на результат** (по коэффициентам модели, при прочих равных):
  - *возраст* — у пациентов старше эффект абляции сильнее, им нужна меньшая поправка
    (например, при −4 D рекомендуемый ввод для 20 лет −4.50, для 40 лет −4.00);
  - *величина коррекции и срок* — регресс пропорционален объёму коррекции;
  - *протокол WFO* — результат в среднем на ~0.3 D миопичнее, чем Custom-Q, поправка нужна больше;
  - *цилиндр* — чем больше цилиндр, тем миопичнее итоговый сфероэквивалент (~0.1 D на 1 D цилиндра);
  - *AL, ACD, оптическая зона* — меньший, но заметный вклад.
- **Астигматизм:** остаточный цилиндр по Tonoref почти не зависит от параметров, которые есть в базе;
  модель лишь немного уточняет ввод цилиндра. Для точного анализа астигматизма в будущем полезны
  субъективная рефракция на контрольных визитах и данные роговичной топографии.

### 4.4. Точность модели

Проверка «честная»: модель каждый раз обучается на части пациентов и проверяется на других
(оба глаза пациента всегда в одной части). Для визитов от 1 месяца и позже:

| Способ | Средняя ошибка сфероэквивалента | В пределах ±0.50 D | В пределах ±1.00 D |
|---|---|---|---|
| Лазер делает ровно то, что ввели | 0.58 D | 57 % | 87 % |
| Одна средняя поправка для всех | 0.50 D | 63 % | 87 % |
| **Модель номограммы** | **0.47 D** | **63 %** | **88 %** |

**80 % глаз в пределах ±0.79 D** от прогноза.

Проверка дообучения: модель, обученная на первых 194 глазах, на следующих 65 «новых» глазах
ошиблась в среднем на **0.49 D** (без поправки — 0.62 D), т.е. номограмма работает и на пациентах,
которых не видела.

Выигрыш пока умеренный, потому что текущая «ручная» поправка уже неплохая, а большая часть
данных — ранний осмотр. Основной ресурс роста точности — **контрольные визиты через 3–6 месяцев**.

### 4.5. Рекомендации по сбору данных

1. Максимально заполнять визиты 3 и 6 мес (сейчас 83 и 28 глаз) — именно они определяют итог.
2. Вносить точную дату/срок раннего осмотра, если он не на 1-е сутки (см. раздел 7).
3. Для гиперметропии (сейчас 12 глаз) номограмма ненадёжна — программа предупреждает об этом;
   нужно ≥ 30 глаз.
4. По возможности добавить колонку фактической глубины абляции с лазера — это позволит
   точнее рассчитывать остаточное ложе.

## 5. Как устроен алгоритм

1. **Векторы рефракции.** Сфера/цилиндр/ось переводятся в векторы Тибоса: M (сфероэквивалент),
   J0 и J45 (астигматизм). Это позволяет корректно усреднять и сравнивать рефракцию и не зависит от
   записи цилиндра с «+» или «−».
2. **Прямая модель.** Для каждого глаза и визита модель учится предсказывать, насколько
   фактический результат отличается от «идеального» (`до операции − введённое в лазер`), в зависимости от
   введённой коррекции, срока после операции, возраста, кератометрии, пахиметрии, лоскута, оптической зоны,
   зрачка, AL, ACD, протокола и глаза. Используется регуляризованная линейная регрессия
   (гребневая или устойчивая к выбросам Хьюбера — выбирается автоматически по точности).
3. **Номограмма = обратная задача.** Для нового пациента перебираются варианты ввода в лазер с шагом
   0.25 D (сфера ±2 D, цилиндр ±1 D от субъективной) и выбирается тот, при котором прогноз на заданный
   срок ближе всего к цели по сфероэквиваленту и остаточному астигматизму.
4. **Безопасность.** Ориентировочная глубина абляции по Мюнерлину, остаточное стромальное ложе,
   PTA; предупреждения при выходе за диапазон обучающих данных.
5. **Дообучение.** Модель полностью переобучается на всех накопленных данных; каждая версия хранится,
   прошлая версия проверяется на новых глазах.

## 6. Ограничения и допущения

- Ранний осмотр «после операции» принят за **1-е сутки**. Если он в другой срок — исправьте в `config.toml`.
- Послеоперационная рефракция — **авторефрактометр (Tonoref II)**, дооперационная — **субъективная**.
  Систематическая разница между ними учитывается моделью, но добавляет шум.
- Глубина абляции — **ориентир по формуле Мюнерлина**, реальная глубина EX500 (Custom-Q/WFO,
  переходная зона) больше. Всегда сверяйтесь с расчётом лазера.
- Гиперметропия (12 глаз), рефракция и возраст вне диапазона базы — прогноз ненадёжен (есть предупреждения).
- Номограмма обучена на ваших данных: один хирург, один лазер, один микрокератом. Для других условий
  нужна своя база.
- Это инструмент поддержки решения, а не медицинское изделие.

## 7. Настройки (`config.toml`)

Файл открывается Блокнотом. После изменений перезапустите программу и переобучите модель.

| Раздел | Что настраивается |
|---|---|
| `[data]` | какие файлы читать (по умолчанию `номограмма.xlsx` и все `.xlsx` из папки `данные`) |
| `[columns]` | соответствие полей программы заголовкам таблицы («группа\|подзаголовок») |
| `[visits]` | контрольные визиты и их срок в месяцах (в т.ч. срок раннего осмотра `"после операции" = 0.033`) |
| `[aliases]` | варианты написания глаза и протокола |
| `[validation]` | допустимые диапазоны значений, исключение глаз с комментарием |
| `[model]` | набор признаков и типы моделей |
| `[planning]` | цель, срок оптимизации, шаг ввода, диапазон поиска, лоскут по умолчанию, пороги RSB и PTA |
| `[table]` | строки и столбцы сводной таблицы номограммы |

**Добавить новый визит** (например, 18 мес): добавьте блок колонок в Excel с заголовком «18 мес» и
подзаголовками `shp`, `cyl`, `axis`, `зрение без коррекции`, затем в `[visits]` строку `"18 мес" = 18`.

**Добавить новый признак** (например, толщину эпителия): добавьте колонку в Excel, пропишите её
в `[columns]` (например, `epi = "до операции|эпителий"`), добавьте диапазон в `[validation.ranges]`
и имя `epi` в список `features_M` раздела `[model]`. Переобучите модель — в отчёте будет видно,
улучшилась ли точность.

## 8. Для технического специалиста

### Структура

```
Запуск.bat / запуск.sh / Запуск.command   запуск (создаёт .venv и ставит зависимости при первом запуске)
config.toml                               все настройки
номограмма.xlsx                           исходная база
данные/                                   дополнительные файлы с результатами (загружаются из интерфейса)
модели/                                   версии модели, актуальная.joblib, история_обучения.csv
результаты/                               отчёты обучения, таблица номограммы, результаты пакетного расчёта
nomogram/                                 исходный код
  data.py      чтение Excel (2-уровневая шапка), проверка, длинный формат «глаз × визит»
  optics.py    векторы Тибоса, роговичный астигматизм, глубина абляции
  model.py     признаки, модели, групповая кросс-валидация
  planner.py   обратная задача (подбор ввода), проверки безопасности, сводные таблицы
  training.py  обучение, версии, проспективная проверка, отчёты
  server.py    локальный веб-сервер (только стандартная библиотека Python)
  web/index.html  интерфейс
  cli.py       командная строка
```

Зависимости: Python ≥ 3.11, pandas, numpy, openpyxl, scikit-learn, joblib (`requirements.txt`).

### Командная строка

```bash
python -m nomogram serve [--port 8765] [--no-browser]   # веб-интерфейс
python -m nomogram check                                # проверка данных -> результаты/проверка_данных.xlsx
python -m nomogram train                                # переобучение
python -m nomogram template                             # шаблон -> планирование/шаблон_планирования.xlsx
python -m nomogram plan файл.xlsx [--horizon 6] [-o out.xlsx]   # пакетный расчёт
python -m nomogram table                                # пересчитать таблицу номограммы
python -m nomogram --config другой.toml train           # альтернативные настройки
```

(При запуске через `Запуск.bat` Python находится в `.venv\Scripts\python.exe`.)

### Перенос на другой компьютер

Скопируйте папку целиком, **кроме `.venv`** (она создаётся заново при первом запуске).
Папки `модели` и `данные` переносить нужно — в них модель и загруженные данные.

## 9. Частые проблемы

| Проблема | Решение |
|---|---|
| «Python 3.11 or newer is not installed» | Установите Python с python.org с галочкой «Add python.exe to PATH», запустите снова |
| Ошибка при первом запуске при установке | Проверьте интернет; удалите папку `.venv` и запустите `Запуск.bat` снова |
| Браузер не открылся | Откройте вручную `http://127.0.0.1:8765` |
| «Программа уже запущена» | Она открыта в другом окне — просто перейдите в браузер по адресу выше |
| «Файл занят другой программой» | Закройте `номограмма.xlsx` в Excel и повторите |
| «Файл не подходит по формату» | Шапка загружаемого файла должна совпадать с `номограмма.xlsx` (2 строки) |
| Модель не обучена | Вкладка «Данные и обучение» → «Переобучить модель» |
| Нужно перенести на другой ПК | См. раздел 8 «Перенос на другой компьютер» |
